# Experiencia Mali

Experiencia interactiva de nostalgia, adaptada a celular.

## Abrir

Abre `index.html` o sirve esta carpeta con un servidor web estático. Para probar micrófono y movimiento en un celular, utiliza HTTPS y acepta los permisos en la pantalla inicial.

El proyecto incluye las imágenes y los audios en `assets/`. No requiere instalación ni compilación.
